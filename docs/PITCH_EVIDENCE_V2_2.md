# V2.2 factual pitch handoff

This is evidence for a later presentation, not a pitch deck. FAQ expectations are those supplied in the project directive; no independent organizer verification is claimed.

## Demonstrable facts

- Public browser app and public TypeScript source; guest calculation without signup or payment.
- Exhaustive shift selection and exact childcare scheduling using the unchanged domain engine, in a real Web Worker.
- Editable fictional example: Sunday $98.40, Saturday $23.20; both $121.60 when two shifts are allowed. These are calculated estimates, not hardcoded recommendations or customer outcomes.
- Full Free weekly decision flow, one saved week, explicit replacement choice and next-week reuse.
- Working Plus Demo: five named local snapshots, history, rename, delete, restore and two-plan recalculation with financial detail.
- Proposed $5.99/month price shown at a real feature gate. Demo unlock grants actual functionality without processing payment.
- 75 automated tests, including all 52 baseline tests and the retained independent optimizer oracle. See QA for exact browser/release evidence and verification limits.

## Suggested 60–90 second demonstration

1. **0–15s:** Open the app → Try an example. Show Sunday and estimated $98.40; expand Where the money goes if time permits.
2. **15–30s:** Save this week. Change limit → Up to two → Your result. Show both shifts and $121.60.
3. **30–45s:** Save this week again → Keep both with Plus. Show Free $0 and proposed Plus $5.99/month. Select Try Plus Demo — No payment required.
4. **45–60s:** Name the plan “Two shifts,” leave the visible copy-Free option selected and save. Both snapshots appear while the Free slot remains available.
5. **60–75s:** Select both records → Compare selected plans. Show $98.40 versus $121.60, the $23.20 estimated difference, and itemized costs. Point out “No payment processed.”
6. **75–90s:** Back to library → Open the first plan. Explain that reload preserves explicit saves and Plan next week copies care assumptions while clearing old offers and requesting reconfirmation.

For a repeated demo, previously saved plans may already exist. Use the library’s named records or deliberately clear only your demo records with confirmation. A full library must be reduced before adding more. Never clear another person’s browser data as part of a demonstration.

## Claims to avoid

Do not claim paying customers, verified demand, recurring revenue, conversion uplift, subscription renewals, proven retention, measured CAC/LTV, guaranteed household savings, actual childcare booking or confirmed availability. The price and repeat-use value are hypotheses. Estimated money kept is after entered incremental costs and assumed withholding, not a tax return or a guarantee. Comparisons between different weeks are scenarios, not a causal savings measurement.

No real billing, login, cloud sync, multi-provider marketplace or automatic draft recovery. The model covers one week, 15-minute increments, up to ten shift offers, one household-rate sitter and explicit care availability; DST transition weeks and complex taxes/benefits are outside scope. Local saved data can be cleared by the browser. No WCAG certification or user-study result is claimed.
